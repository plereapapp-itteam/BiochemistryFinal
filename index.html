▪Final Board Distractor Pairs

  • PFK-1 = glycolysis; F-1,6-bisphosphatase = gluconeogenesis.
  • PDH makes acetyl-CoA; pyruvate carboxylase makes OAA.
  • Glycogen synthase builds; glycogen phosphorylase breaks.
  • ACC makes malonyl-CoA; CPT-I is inhibited by malonyl-CoA.
  • Mitochondrial HMG-CoA synthase = ketogenesis; HMG-CoA reductase = cholesterol synthesis.
  • Fructokinase deficiency = benign; aldolase B deficiency = severe hypoglycemia.
  • Galactokinase deficiency = mainly cataracts; GALT deficiency = systemic galactosemia.
  • McArdle = muscle phosphorylase; Hers = liver phosphorylase.
  • Von Gierke = ER glucose-6-phosphatase; Pompe = lysosomal acid α-glucosidase.
  • DKA = excessive ketones; MCAD deficiency = insufficient ketones during fasting hypoglycemia.

▪Respiratory Acidosis / Alkalosis

Respiratory acidosis
  • DΦHypoventilation → PaCO₂ ↑ → H⁺ ↑ → pH ↓.

  • DΦHyperventilation → PaCO₂ ↓ → H⁺ ↓ → pH ↑.

🏁Final PLE Mental Checklist — All Systems

🥩 Protein Metabolism
  • Protein digestion: trypsin is the major zymogen-activation hub.
  • Transamination: PLP/B6.
  • Nitrogen collector: glutamate.
  • Ammonia carrier: glutamine.
  • Urea rate-limiting enzyme: CPS I + NAG.
  • Urea energy cost: 3 ATP / 4 high-energy bonds.
  • OTC: hyperammonemia + orotic acid ↑.
  • Heme rate-limiting enzyme: ALA synthase + B6.
  • Lead: inhibits ALA dehydratase + ferrochelatase.
  • AIP: PBG ↑, abdominal/neuro symptoms, no photosensitivity.
  • PCT: uroporphyrins ↑ + photosensitivity.
  • Bilirubin: UGT1A1 = conjugation; MRP2 = secretion; indirect = not in urine; direct = can appear in urine.
🧵 Amino Acid & Protein Biochemistry
  • pH < pI = positive; pH > pI = negative.
  • Denaturation destroys higher-order structure, not usually peptide bonds.
  • SDS-PAGE = size; isoelectric focusing = pI; ion exchange = charge; affinity = specific ligand.
  • Size exclusion: large proteins elute first.
  • Collagen = Gly-X-Y; glycine every third residue.
  • Vitamin C → prolyl/lysyl hydroxylases.
  • Copper → lysyl oxidase.
  • Scurvy = defective hydroxylation; Menkes = defective cross-linking.
  • OI = type I collagen; Alport = type IV collagen.
  • APP: α-secretase = safe/nonamyloidogenic; β + γ = Aβ-producing.
  • Aβ = extracellular plaque; tau = intracellular tangle.
  • AD biomarker pattern = CSF Aβ ↓ + phosphorylated tau ↑; APP chromosome 21; APOE ε4 increases risk.
🧬 Genetics & Enzymes
  • Enzymes lower activation energy but do not change ΔG or Keq.
  • Km = [S] at ½Vmax; low Km generally means greater apparent affinity.
  • Enzyme amount ↑ → Vmax ↑, Km unchanged.
  • Competitive = Km ↑ / Vmax same.
  • Pure noncompetitive = Km same / Vmax ↓.
  • Uncompetitive = Km ↓ / Vmax ↓.
  • Allosteric = rapid/noncovalent; phosphorylation = rapid/covalent; gene induction = slow/change in enzyme amount.
  • Histone acetylation generally activates; DNA methylation generally represses gene expression.
  • Southern = DNA; Northern = RNA; Western = protein; RT-PCR = RNA; FISH = chromosomal location/rearrangement.
  • Oncogene = gain-of-function accelerator; tumor suppressor = loss-of-function brake; DNA-repair defect = mutation accumulation.
💪 Musculoskeletal / Bioenergetics
  • I, III, IV pump protons; II does not.
  • NADH = ~2.5 ATP; FADH₂ = ~1.5 ATP.
  • Uncoupler → ATP ↓, O₂ consumption ↑, heat ↑.
  • TCA per acetyl-CoA = 3 NADH + 1 FADH₂ + 1 GTP ≈10 ATP.
  • Phosphocreatine = immediate muscle ATP buffer.
  • PFK-1 = muscle glycolysis control; free glucose 2 ATP, glycogen 3 ATP anaerobically.
  • HGPRT deficiency = Lesch–Nyhan → urate ↑.
  • ADA deficiency = dATP ↑ → SCID.
  • CPS II = cytosolic pyrimidine enzyme, PRPP activates, UTP inhibits.
  • Orotate + NH₃ ↑ = OTC; orotate ↑ without hyperammonemia = UMP synthase deficiency.
🫁 Respiratory System
  • Right shift = CO₂, H⁺, temperature, 2,3-BPG ↑ → O₂ unloading ↑.
  • Left shift = HbF, CO, alkalosis, hypothermia → O₂ affinity ↑.
  • PaO₂ measures dissolved O₂—not total oxygen content.
  • CO poisoning can have normal PaO₂; confirm with co-oximetry.
  • CO₂ travels mainly as HCO₃⁻ through carbonic-anhydrase chemistry.
  • Sickle = qualitative Hb defect; thalassemia = quantitative chain-synthesis defect.
  • Respiratory acidosis: pH ↓ / PaCO₂ ↑; respiratory alkalosis: pH ↑ / PaCO₂ ↓.
  • Metabolic acidosis: pH ↓ / HCO₃⁻ ↓; metabolic alkalosis: pH ↑ / HCO₃⁻ ↑.
  • Winter’s formula evaluates respiratory compensation in metabolic acidosis SUPPLEMENTARY.
  • For this analysis-heavy TOS row, master O₂–Hb curve direction + ABG compensation + hemoglobinopathy laboratory patterns above all else.
🥗 Nutrition
  • Positive energy balance = weight gain; negative energy balance = weight loss.
  • Positive N balance = growth/pregnancy; negative N balance = trauma/starvation/infection.
  • Kwashiorkor = edema; marasmus = severe wasting.
  • B1–TPP; B2–FAD/FMN; B3–NAD/NADP; B5–CoA; B6–PLP; B7–biotin; B9–THF; B12–cobalamin.
  • Vitamin C = collagen hydroxylation; vitamin K = clotting-factor γ-carboxylation.
  • Vitamin D deficiency: check 25-OH vitamin D.
  • B12 deficiency: methylmalonic acid ↑; folate deficiency does not cause this.
  • Hepcidin ↑ → ferroportin ↓ → circulating iron availability ↓.
  • Factor VIII/IX deficiency → aPTT ↑; factor VII/Vit K defect → PT ↑.
  • Factor XII deficiency = aPTT ↑ without bleeding.
  • Thrombin makes fibrin; plasmin breaks fibrin; D-dimer reflects breakdown of cross-linked fibrin.
  • Albumin = oncotic pressure; transferrin = iron transport; ferritin = iron storage; haptoglobin = binds free Hb.
🛡️ Immunology
  • Innate = rapid/pattern-based; adaptive = antigen-specific + memory.
  • CGD = NADPH oxidase defect; DHR abnormal.
  • C3b = opsonization; C5a = chemotaxis; C5b-9 = MAC.
  • Terminal complement deficiency = recurrent Neisseria.
  • IL-2 = T cells; IL-5 = eosinophils; IL-8 = neutrophils; IFN-γ = macrophages.
  • MHC I = endogenous antigen + CD8.
  • MHC II = exogenous antigen + CD4.
  • MHC I uses proteasome + TAP + ER.
  • MHC II uses endosome + invariant chain/CLIP + HLA-DM.
  • For this 10-item row, master defect → missing immune function → infection pattern → confirmatory immune assay.
🫀 Cardiovascular System
  • Normal myocardium is overwhelmingly oxidative and preferentially uses fatty acids.
  • AMP ↑ → AMPK ↑ → ACC-2 ↓ → malonyl-CoA ↓ → CPT-I activity ↑ → FA oxidation ↑.
  • Ischemia → ATP ↓ + glycolysis/lactate ↑ + pH ↓.
  • Persistent ischemia → myocyte necrosis → troponin ↑.
  • PDH requires B1/B2/B3/B5 + lipoate.
  • HMG-CoA reductase = rate-limiting cholesterol synthesis enzyme.
  • Insulin activates cholesterol synthesis; AMPK inhibits it.
  • LDLR defect → LDL ↑ → premature CAD.
  • PCSK9 degrades LDL receptors → LDL rises.
  • Heart failure → SNS/RAAS ↑ acutely; chronic excess becomes maladaptive.
  • Thiamine deficiency → PDH/α-KGDH ↓ → lactate ↑ + cardiac ATP impairment.
  • PLE reasoning: identify the energy/lipoprotein/signaling defect → locate the key enzyme → predict metabolite/biomarker change → connect it to ischemia, HF, or atherosclerosis → select troponin, LDL-C/genetic testing, BNP, lactate, or the appropriate biochemical confirmation.
